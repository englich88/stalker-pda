# STALKER PDA — Arduino PWA

## Установка на iPhone
1. Разместите содержимое этой папки на HTTPS-хостинге (например GitHub Pages).
2. Откройте опубликованный HTTPS-адрес в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Запустите приложение с новой иконки.

PWA нельзя надёжно установить простым открытием локального HTML-файла: нужен HTTPS-хостинг (localhost — исключение для разработки).

## Подключение Arduino / ESP32
В приложении предусмотрен API:
- `GET http://IP-АДРЕС/api/status`
  `{"connected":true,"temperature":23.4,"humidity":45,"relays":[true,false,false,false]}`
- `POST http://IP-АДРЕС/api/relay`
  `{"id":1,"state":true}`

Замените адрес `192.168.4.1` в исходном коде в переменной `host` либо задайте его в localStorage через консоль браузера:
`localStorage.setItem('pdaHost','http://192.168.1.50')`

## Важно про iPhone и локальную сеть
- iPhone и контроллер должны быть в одной Wi-Fi сети.
- HTTPS-страница, обращающаяся к HTTP Arduino API, может блокироваться политиками браузера (mixed content). Для надёжной работы используйте HTTPS на контроллере/шлюзе или разместите интерфейс локально с подходящей схемой доступа. Для простого ESP32 AP/HTTP режима возможны ограничения Safari.
- Сервер Arduino должен поддерживать CORS для origin опубликованного сайта и OPTIONS preflight для JSON POST.
- PWA offline-кэширует интерфейс, но для команд Arduino сеть необходима.
- Проверьте логику выходов до подключения нагрузки; не полагайтесь на приложение как на защиту опасного оборудования.
